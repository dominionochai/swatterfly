# Verified repository references

The entries below are the requested verified repository/tool list. Descriptions state project relevance; **stretch** marks material that is optional or intentionally deferred. They are references, not dependencies or claims that every project has been audited for current compatibility.

## Looming and event vision

- [`github.com/fuqinbing/LGMD2-open-source`](https://github.com/fuqinbing/LGMD2-open-source) — C# LGMD2 implementation/reference; MIT reference and a candidate porting reference for the looming layer.
- [`github.com/FabianSchubert/Bio-Inspired-Event-Based-Looming-Object-Detection-for-Automotive-Collision-Avoidance`](https://github.com/FabianSchubert/Bio-Inspired-Event-Based-Looming-Object-Detection-for-Automotive-Collision-Avoidance) — bio-inspired event-based looming and collision-avoidance reference; relevant to detector evaluation.
- [`github.com/SensorsINI/v2e`](https://github.com/SensorsINI/v2e) — video-to-events conversion for synthetic/recorded inputs; relevant to sim-to-event validation.
- [`github.com/uzh-rpg/rpg_esim`](https://github.com/uzh-rpg/rpg_esim) — event-camera simulator; relevant to controlled event streams.
- [`github.com/uzh-rpg/dagr`](https://github.com/uzh-rpg/dagr) — event-based vision research code; relevant as a stretch perception reference.
- [`github.com/Event-AHU/Event_Camera_in_Top_Conference`](https://github.com/Event-AHU/Event_Camera_in_Top_Conference) — event-camera paper/code index; relevant for surveying modern methods.

## Guidance and vehicle control

- [`github.com/braanan/pure-proportional-navigation-example`](https://github.com/braanan/pure-proportional-navigation-example) — compact PN example; relevant for an interpretable baseline.
- [`github.com/gedeschaines/propNav`](https://github.com/gedeschaines/propNav) — proportional-navigation reference; relevant to cross-checking guidance math.
- [`github.com/alti3/missile-proportional-navigation-python`](https://github.com/alti3/missile-proportional-navigation-python) — Python PN example; relevant only as a simulation/math reference, not as a flight implementation.
- [`github.com/Woreira/Unity-Proportional-Navigation-Collection`](https://github.com/Woreira/Unity-Proportional-Navigation-Collection) — Unity PN collection; relevant for visualization and stretch simulation.
- [`github.com/PX4/PX4-Autopilot`](https://github.com/PX4/PX4-Autopilot) — autopilot stack; relevant to SITL and eventual Offboard integration.
- [`mavsdk.mavlink.io`](https://mavsdk.mavlink.io) — MAVSDK documentation; relevant to a typed vehicle-command boundary.
- [`ardupilot.org/dev/docs/copter-commands-in-guided-mode.html`](https://ardupilot.org/dev/docs/copter-commands-in-guided-mode.html) — Guided-mode command documentation; relevant as the ArduPilot alternative.
